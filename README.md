# Administrativo SERMAS · Estudio y test

App de estudio para la oposición de **Grupo Administrativo de la Función Administrativa (C1) del SERMAS**: temario, resúmenes, test con la puntuación real del examen (+1 / −0,25), corrección, estadísticas, repaso de fallos, tarjetas de memoria y tablas de plazos.

- Se instala en tablet, móvil u ordenador y **funciona sin internet**.
- Se adapta al **girar la pantalla**: en horizontal muestra dos columnas.
- El progreso se guarda **en cada dispositivo**. Para pasarlo a otro, usa «Guardar copia» y «Recuperar copia» (al pie de la app).

> Herramienta de estudio no oficial. Comprueba siempre los datos en el BOE, el BOCM y la web de la convocatoria.

## Publicarla en GitHub Pages (una sola vez, unos 5 minutos)

1. Entra en [github.com](https://github.com) con tu cuenta y pulsa **New repository** (botón verde o el **+** de arriba).
2. Nombre: `oposiciones-sermas` · márcalo como **Public** · pulsa **Create repository**.
3. En el repositorio vacío, pulsa **uploading an existing file** (o **Add file → Upload files**).
4. Arrastra **todo el contenido** de esta carpeta, sin la carpeta en sí:
   `index.html`, `sw.js`, `manifest.webmanifest`, `.nojekyll`, `README.md` y la carpeta `icons`.
   *En iPhone/iPad: descomprime el zip en la app Archivos, pulsa «choose your files» y selecciónalos.*
5. Pulsa **Commit changes**.
6. Ve a **Settings → Pages**. En **Branch** elige `main` y carpeta `/ (root)` y pulsa **Save**.
7. Espera 1-2 minutos y recarga esa página: aparecerá la dirección de la app, algo así como
   `https://TU-USUARIO.github.io/oposiciones-sermas/`

Esa dirección es la que puedes compartir por WhatsApp o donde quieras.

## Instalarla en la tablet o el móvil

- **iPad / iPhone (Safari):** abre la dirección → botón **Compartir** → **Añadir a pantalla de inicio**.
- **Android (Chrome):** abre la dirección → aparecerá **Instalar app** (o menú ⋮ → **Instalar app**).
- **Ordenador (Chrome o Edge):** icono de instalar en la barra de direcciones.

La primera vez se abre con internet; a partir de ahí funciona sin conexión.

## Actualizar la app

Cuando haya una versión nueva (por ejemplo, el temario oficial 2026):

1. En el repositorio, **Add file → Upload files** y sube los archivos nuevos (`index.html` y `sw.js` como mínimo). GitHub sustituye los antiguos.
2. **Commit changes**.

Quien tenga la app instalada verá el aviso **«Hay una versión nueva de la app · Actualizar ahora»** la próxima vez que la abra con internet. Su progreso se conserva.
